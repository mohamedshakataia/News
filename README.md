# 📰 News App

A Flutter application for fetching and displaying real-time breaking news across various categories using NewsAPI.

---

## 🎨 Features

- 🌐 Fetch live news articles dynamically using **NewsAPI**.
- 📂 Category browsing (General, Sports, Business, Health, Entertainment, Science, Technology).
- 🖼️ Smooth image loading and caching using `cached_network_image`.
- 📜 Seamless scrolling UI using Flutter `CustomScrollView` and `Slivers`.
- 🔄 State handling for loading indicators, success states, and error handling.
- 🔗 Direct access to full articles via web view integration.

---

## 🛠️ Technologies

- Flutter
- Dart
- Material Design
- `dio` / `http` package (REST API integration)
- `cached_network_image`
- NewsAPI service

---

## 🎯 Project Purpose

This project was created to practice Flutter asynchronous programming, integrating RESTful APIs, parsing JSON data into model objects, state management, and building performant scrollable layouts using Slivers.
